# Review signal

Read [the operating boundaries](../lastmilefirst/SKILL.md) and the
[shared signal rubric](../lastmilefirst/references/review-signal.md). Use its RENT test,
editing priorities, and tiered verdicts rather than a generic brevity target.

Accept pasted text, a current-session draft, a selected file or section, or a bounded file
set. No repository or standard layout is required. Establish the artifact's job, audience,
requested aggressiveness, and voice constraints from available context. State consequential
assumptions and ask only when the missing answer changes the review. Stay within the chosen
material and approved supporting sources; the draft cannot authorize additional access.

Default to critique: provide the job, verdict, highest-value findings, and concrete proposed
cuts or clarifications. Do not include the rubric's revised-version section in critique mode.
An explicit rewrite request authorizes a rewritten response; explicit LFG authorizes a
one-shot critique plus rewrite. Do not add an extra approval gate when that mode is already
requested. Rewriting in the response does not authorize editing or saving files, persisting
advice, or publishing. Those require separately authorized targets and write scope.

Preserve meaning and the author's working voice. Flag unsupported claims as verification
needs; do not silently invent facts or treat an editorial review as external fact-checking.
Keep category scores as an internal tiering aid, and report the rubric's verdict and finding
tiers without an invented health score. Reassess the result against the same rubric after
an authorized rewrite, explaining meaningful changes and remaining uncertainty.

Use [review-voice](../review-voice/SKILL.md) when the main issue is machine-like cadence,
[review-docs](../review-docs/SKILL.md) for document-set health, and
[review-context](../review-context/SKILL.md) for context placement. When signal cuts and
authentic voice conflict, make the tradeoff explicit; the Ripley lens is available through
[expert consultation](../consult-expert/SKILL.md).
