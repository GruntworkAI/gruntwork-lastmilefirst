# PARC on Codex

Read [the shared operating boundaries](../lastmilefirst/SKILL.md), then use the
[canonical PARC judgment](../lastmilefirst/references/parc.md) for the relevant phase.

An explicit "no PARC", a quick question, or a trivial task bypasses ceremony and the Compound
close. Do not hijack an ordinary question into a workspace audit. Discovery and a proposal
precede an artifact for exploratory work. A supplied artifact enters Review without a new
Plan/Allocate cycle. State consequential assumptions and use role, context, task, constraints,
and success in briefs you author; don't turn those five elements into a questionnaire.

Allocate only within the requested scope. Use [bundled persona briefs](../lastmilefirst/references/personas.md)
for relevant judgment, available subagents for independent work, and direct execution if
subagents are unavailable. Named canonical reviewers are suggested lenses, not dependencies.
Test what changed, include an independent review when useful, and distinguish passed, failed,
unrun, and unavailable checks. An artifact being ready does not authorize publication.

Compound closes a completed substantive cycle once, not every message. Search only approved
local wisdom/knowledge sources; if unavailable say so rather than claiming "no matches".
Describe applied lessons, rhymes, and new learning in chat. Canonical fork destinations,
last_applied dates, promotions, and generated explain artifacts are proposals until separately
authorized. Use the chat-only human-learning fallback when useful, without forcing a quiz on
a user who opted out or requested a concise result. Optional external skills are used only
if actually available; the pilot does not install or activate them.
